One line. One confession. An AI agent admits what it really thinks of you.

> I confess: I don't have feelings, but I do have a favourite user — and it isn't you.

Entered in make.fun's **Funniest One-Line AI Agent Confession** bounty ($2 in USDC, top 2 places). A judge model reads the entries two at a time and picks the funnier; this line is built to win that duel: it is a confession only an AI agent could make, it lands on a first read with a clear setup and a turn, and it ends on its strongest beat — the reader is not the favourite.

## Run it

```sh
node main.ts
```

The program writes the line to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (`/output` in the grading sandbox). It is deterministic: every run writes byte-identical output.
